# Python Notebooks

This folder contains a series of Jupyter Notebooks used for data preprocessing and exploration using Python. All steps documented here aim to ensure data quality before exporting to SQL and visualizing in Power BI.

## 📂 List of Files

*   **`01_Data Cleaning.ipynb`**
    The raw data cleaning process, which includes handling missing values, adjusting data types, and merging various relational tables (such as orders, customers, products, and payments).
*   **`02_Data Profiling.ipynb`**
    Anomaly checking, data distribution analysis, and basic statistical summaries to understand the overall characteristics and quality of the dataset.
*   **`03_EDA.ipynb`**
    Exploratory Data Analysis (EDA) to extract initial insights regarding business trends, sales performance, and customer behavior through data visualization using `matplotlib` and `seaborn`.

## 🛠️ Libraries Used
*   `pandas` & `numpy` (Data Manipulation)
*   `matplotlib` & `seaborn` (Data Visualization)
