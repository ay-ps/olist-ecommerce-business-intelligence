# 📊 Power BI Dashboard

This folder stores the interactive dashboard file, which serves as the final deliverable for this Business Intelligence project.

## 📂 List of Files

*   **`Olist_Ecommerce_Business_Intelligence.pbix`**
    The main Power BI report file. This file contains the Data Modeling, measure creation using DAX (Data Analysis Expressions), and interactive visualizations that summarize all key insights from the Olist E-Commerce dataset.

> **Note:** To view a visual preview of this dashboard without opening the `.pbix` file, please refer to the screenshots available in the `images/` directory of this repository.
