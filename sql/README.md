# 🗄️ SQL Analysis

This folder contains the SQL scripts used to extract business insights from the cleaned dataset. This analysis utilizes the **PostgreSQL** dialect.

## 📂 List of Files

*   **`olist_business_analysis.sql`**
    A comprehensive set of queries designed to answer the core business questions outlined in the Business Requirements. These queries extract metrics for:
    *   Sales Performance Trends
    *   Customer Behavior Analysis
    *   Product & Seller Performance Evaluation
    *   Delivery Efficiency

> **Note:** The result sets from these SQL queries serve as the primary data foundation for building the dashboard in Power BI.
